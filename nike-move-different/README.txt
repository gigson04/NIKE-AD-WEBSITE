NIKE — MOVE DIFFERENT campaign website

FILES
- index.html: complete responsive website (HTML, CSS, and JavaScript in one file)

HOW TO RUN
1. Extract the ZIP folder.
2. Open index.html in a modern browser, or open the folder in VS Code and use Live Server.
3. Internet access is needed for the remote font, logo, and product photography assets.

FUNCTIONS INCLUDED
- Responsive desktop and mobile navigation
- Product category filters and search
- Wishlist toggles
- Shopping bag drawer with item counts, removal, and subtotal
- Newsletter form demo feedback
- Keyboard escape handling and reduced-motion support

IMPORTANT
This is a portfolio/demo concept, not an official Nike store. Product names, photos, prices, and availability are illustrative. The cart and newsletter are front-end demos only; no order or email is actually sent. Verify image licenses, official product information, and trademark requirements before commercial launch.
